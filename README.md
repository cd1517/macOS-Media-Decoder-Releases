# HoverPreview Decoder Releases

This public repository contains optional, architecture-specific decoder component releases for HoverPreview.

- The HoverPreview app does not bundle these binaries.
- A download starts only after the user explicitly confirms installation.
- Each release includes its upstream licenses and is verified by exact size and SHA-256 before installation.
- Apple Silicon and Intel Macs download separate archives.

The component is built from the pinned official mpv source and is shared by all enabled extended video formats. It reads media files directly; it does not create a compatible copy for every video.
